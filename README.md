# openclaw / Genie Google OAuth information

Static informational pages for the owner's personal AI assistant. No application server, user data, OAuth credentials, API keys, analytics, or sign-in flow belong in this repository.

- `index.html`: application overview
- `privacy.html`: Google integration privacy notice
- `terms.html`: usage information
- `style.css`: responsive styling

Keep the existing academy mobile-app policy separate. Verify the published site in Google Search Console before using it for OAuth branding. Publication alone does not mean Google has accepted the domain or completed verification.
