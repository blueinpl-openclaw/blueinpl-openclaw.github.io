GOOGLE WORKSPACE / PRIVACY

Google 연동
개인정보처리방침

시행일: 2026년 10월 24일

이 방침은 개인 AI 비서 지니(openclaw)가 연결된 Google 계정의 데이터를 처리하는 방법을 설명합니다. 강남 실내 테니스 아카데미 회원용 앱의 일반적인 회원정보 처리방침과는 별도입니다.

1. 운영자와 적용 대상

지니는 운영자 본인의 업무를 보조하는 개인용 서비스입니다. Google 계정 소유자가 OAuth 동의 화면에서 연결을 허용한 계정에만 접근합니다. 문의 및 삭제 요청 연락처는 blueinpl@gmail.com입니다.

2. 처리하는 Google 데이터

  • 계정 식별: 연결 계정의 이메일 주소와 기본 프로필 정보.
  • Gmail: 요청 처리에 필요한 메일의 발신자·수신자·제목·본문·첨부 정보, 라벨·필터 등 메일함 관련 정보. 실제 첨부 내용은 관련 작업에 필요한 경우 처리할 수 있습니다.
  • Google Calendar: 접근 가능한 캘린더 목록, 일정 제목·설명·시간·장소·참석자 등 일정 정보.
  • 인증 정보: Google API 접근을 유지하기 위한 OAuth 토큰 및 앱 인증 설정.

연결 시 표시되는 Google 동의 화면에서 허용 범위를 확인할 수 있습니다. 현재 Google 연동에는 메일 읽기·작성·전송 및 메일 설정 관련 권한과 캘린더 관리 권한이 포함됩니다. 요청하지 않은 작업을 수행하기 위한 용도로 사용하지 않습니다.

3. 이용 목적

데이터는 운영자가 요청한 메일 검색·요약·초안 작성·전송·메일함 관리, 일정 조회·생성·변경·삭제와 이에 필요한 오류 확인 및 보안을 위해 처리합니다. Google 사용자 데이터를 판매하거나 광고 타기팅을 위해 이용하지 않습니다. 앱 자체에서 범용 AI 모델을 학습시키기 위한 데이터셋으로 수집하지 않습니다.

4. AI 및 외부 서비스에서의 처리

Telegram으로 받은 요청은 openclaw와 설정된 AI 모델이 해석하고, 노트북의 Google 연동 도구가 API 작업을 실행합니다. 요청을 처리하는 데 필요한 메일·일정 내용의 일부가 AI 입력에 포함되거나 처리 결과가 Telegram 메시지로 전달될 수 있습니다.

  • Google: OAuth 인증, Gmail·Calendar API 및 현재 설정된 Gemini AI 모델을 통한 요청 해석·응답 생성.
  • Telegram: 운영자의 요청과 비서 응답을 전달하는 메시징 서비스.
  • GitHub Pages: 이 공개 안내 페이지의 정적 파일 호스팅. 이 사이트에는 메일·일정·OAuth 토큰을 게시하지 않습니다.

각 제공자의 처리·보관 조건은 해당 서비스의 정책과 계정 설정도 적용됩니다. 민감한 내용은 필요한 범위로만 요청하거나 공유해 주세요. Google API로 받은 데이터의 사용과 다른 앱으로의 전달은 Google API Services User Data Policy의 Limited Use 요건에 따라 요청된 사용자 기능을 제공하는 범위로 제한합니다.

5. 저장과 보관

OAuth 인증 정보는 운영자의 노트북 자격 증명 저장소에서 관리합니다. 비서의 대화 기록과 작업 로그에는 처리한 요청 또는 결과가 포함될 수 있으며, 운영자가 해당 기록을 정리하거나 삭제할 때까지 보관될 수 있습니다. Telegram 대화 및 외부 제공자가 관리하는 기록은 각 서비스에서 별도로 관리됩니다.

인증 정보는 연결 유지에 필요한 동안 보관합니다. 연결 해제와 토큰 철회는 이후 Google API 접근을 막지만, 이미 작성된 대화·작업 로그나 전달된 메시지를 자동으로 삭제하지는 않습니다.

6. 연결 철회와 삭제 요청

Google 계정의 서드 파티 연결 설정에서 openclaw의 접근을 철회할 수 있습니다. 저장된 로컬 인증 정보·작업 기록 삭제, 처리 정보 확인 또는 정정은 운영자에게 요청할 수 있습니다. Telegram 메시지는 Telegram에서도 별도로 삭제할 수 있습니다.

7. 보호 조치와 공개 페이지

Google API 및 외부 서비스와의 통신에는 해당 서비스가 제공하는 암호화 연결을 사용합니다. 인증키와 토큰을 공개 페이지나 공개 코드 저장소에 포함하지 않습니다. 이 안내 사이트에는 로그인, 입력 폼 또는 자체 분석 도구가 없습니다. 호스팅 제공자는 사이트 제공 및 보안을 위해 접속 정보를 처리할 수 있습니다.

8. 변경과 문의

연동 기능이나 데이터 처리 방법이 변경되면 이 페이지의 내용과 시행일을 갱신합니다. 문의: blueinpl@gmail.com.
